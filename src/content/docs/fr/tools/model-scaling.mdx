**Model Scaling** ne redimensionne pas le modèle par lui-même. Il affiche l'interface d'**Immersive Scaler**, une extension séparée conçue pour redimensionner les avatars à une taille cible et corriger leurs proportions pour la VR.

## Installer Immersive Scaler

Le panneau vous indique ce qu'il a trouvé :

| Message                                | Que faire                                                                                                         |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Immersive Scaler is not installed!** | Cliquez sur **Download Immersive Scaler**, installez comme extension le zip de sa page de versions, puis revenez. |
| **Immersive Scaler is not enabled!**   | Cliquez sur **Enable Immersive Scaler**. Cats désactive les anciennes copies et active la version actuelle.       |

Cats nécessite Immersive Scaler 0.5.2 ou plus récent. Une fois installé et activé, ses commandes apparaissent directement dans ce panneau.

## L'utiliser

Les commandes appartiennent à Immersive Scaler, dont le guide fait donc référence : cliquez sur **Immersive Scaler Help** en haut du panneau pour l'ouvrir.

<Aside type="tip">
	Redimensionnez l'avatar avant de créer le suivi oculaire ou les visèmes, et avant d'exporter.
	Changer la taille ensuite peut décaler les os des yeux et les shape keys.
</Aside>
