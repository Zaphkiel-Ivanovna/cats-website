**Custom Model Creation** kombiniert Modelle. Es hat zwei Bereiche: **Merge Armatures**, um zwei geriggte Modelle zu einem zu vereinen, und **Attach Mesh**, um ein nicht geriggtes Objekt an einen einzelnen Knochen zu heften.

## Merge Armatures

Damit lässt sich ein geriggtes Outfit, eine Frisur oder ein Körperteil auf einen Avatar setzen. Der Bereich benötigt mindestens zwei Armaturen in der Szene; bei weniger zeigt er nur **Two armatures are required!**

### Vor dem Zusammenführen

- [Fix MMD Model](../mmd-options/) auf beide Modelle anwenden, wenn es rohe MMD- oder VRM-Importe sind, damit ihre Knochen dieselben Standardnamen tragen.
- Nur das **Mesh** des hinzuzufügenden Modells an seinen Platz bewegen. Cats bewegt dessen Knochen passend zur Basisarmatur.
- Keine der beiden Armaturen darf ihre Daten mit einem anderen Objekt teilen. Ist das der Fall, zuerst **Object > Relations > Make Single User** ausführen.

### Zusammenführen

<Steps>

1. Unter **Base** die Armatur wählen, die bleibt: meist den Avatar.

2. Unter **To Merge** die hinzuzufügende Armatur wählen.

3. Zeigt Cats **Armatures can be merged automatically!**, teilen beide ihre Hauptknochennamen, und es kann weitergehen. Andernfalls unter **Attach to** den Knochen der Basisarmatur wählen, an dem das neue Teil hängen soll.

4. Die Optionen einstellen und auf **Merge Armatures** klicken.

</Steps>

Cats meldet **Armatures successfully joined.** Knochen mit gleichem Namen werden zusammengeführt und ihre Gewichte addiert.

| Option                       | Standard | Wirkung                                                                                                                                                                                                                 |
| ---------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Merge All Bones**          | Aus      | Führt alle Knochen mit gleichem Namen zusammen, nicht nur die Hauptknochen (Hips, Spine und so weiter). Die zusammenzuführenden Knochen passend umbenennen. Das Ergebnis danach prüfen: Dies kann Nebenwirkungen haben. |
| **Apply Transforms**         | Aus      | Aktivieren, wenn beide Modelle bereits genau an der richtigen Stelle stehen. Sie bleiben beim Zusammenführen an Ort und Stelle.                                                                                         |
| **Join Meshes**              | An       | Vereint nach dem Zusammenführen alle Meshes zu einem.                                                                                                                                                                   |
| **Remove Zero Weight Bones** | An       | Löscht nach dem Zusammenführen Knochen, die keine Vertices bewegen.                                                                                                                                                     |
| **Cleanup Shape Keys**       | An       | Entfernt wirkungslose Shape Keys. Deaktivieren, falls benötigte Shape Keys verschwinden.                                                                                                                                |

### Transformationsfehler

Das Zusammenführen erwartet beide Armaturen im gleichen Maßstab und das hinzugefügte Modell ohne Rotation. Ist das nicht der Fall, bricht Cats mit **Transform Issue Detected!** ab. Entweder **Apply Transforms** aktivieren oder beide Objekte auswählen und ihre Transformationen mit <kbd>Ctrl</kbd> + <kbd>A</kbd> > **All Transforms** anwenden.

Hat eine Armatur ein Elternobjekt, muss dieses auf Position 0, Rotation 0 und Maßstab 1 stehen oder seine Transformationen angewendet haben.

## Attach Mesh

Gedacht für starre Accessoires: einen Hut, eine Brille, eine Waffe. Das Mesh darf noch kein Elternobjekt haben.

<Steps>

1. Unter **Base** die Armatur wählen.

2. Unter **Mesh** das Mesh ohne Elternobjekt wählen.

3. Unter **Attach to** den Knochen wählen, dem es folgen soll, etwa Head für einen Hut.

4. Auf **Attach Mesh** klicken.

</Steps>

Cats ordnet das Mesh der Armatur unter, erstellt unter dem gewählten Knochen einen neuen, nach dem Mesh benannten Knochen und gewichtet das ganze Mesh auf ihn. Die Meldung lautet **Mesh successfully attached to armature.**

<Aside type="caution">
	Attach Mesh löscht die vorhandenen Vertex-Gruppen des Meshes und weist jeden Vertex einem einzigen
	Knochen zu. Das eignet sich nur für starre Objekte: Eine Jacke oder ein Rock braucht mehrere
	Knochen und verformt sich sonst falsch. Den Maßstab des Meshes vorher anwenden, falls er nicht
	einheitlich ist.
</Aside>
